# RepoMap v0.0.1 Release Notes

**Release Date:** September 15, 2026  
**Source Tag/Commit:** v0.0.1  
**Distribution:** Public Source Preview (Pre-publication with respect to package managers)

RepoMap v0.0.1 is the first public source release of RepoMap, an open-source deterministic repository knowledge graph engine for polyglot software repositories.

## Highlights

- **Deterministic Code & Architecture Graph**: Extracts verifiable facts from Python, Go, Nix, Shell, PowerShell, and documentation files without probabilistic or hallucinated edges.
- **Model Context Protocol (MCP)**: Native stdio server enabling AI coding assistants (such as Antigravity, Claude Desktop, and Cursor) to query symbol definitions, dependencies, and architecture neighborhoods.
- **Local-First Containerized Execution**: Single-command setup running against isolated PostgreSQL containers via `repomap-kg local up`.
- **Pure Canonical Model**: Decouples physical source paths and ephemeral parser artifacts from logical symbol identities and relational edges.

## Release & Versioning Policy

- Versions `0.0.x` are source-only preview releases.
- Package manager publication (PyPI, npm, Go modules, container registries) will begin with version `0.1.0`.
- The `main` branch tracks released public versions; subsequent development occurs on `staging`.

## Known Limitations in v0.0.1

- **Coordinator Interruption Recovery**: Recovery of in-flight coordinator jobs following an abrupt container crash or daemon termination is experimental and currently requires manual job reconciliation.
- **Multi-Source Composition**: Cross-repository graph merging is in active development and scheduled for upcoming releases.
