## Decision

Preserve the intended172-name canonical facade and291-name compatibility
ledger. Explicitly classify only claim_guard and rust_pilot_family as internal
non-facade package children; exclude them consistently from export/inventory
checks, and test late imports plus refusal of an unclassified public child.

Cache admitted original ordinal/observation pairs during the existing claim
filtering pass. Canonical dispatch consumes that cache without rescanning raw
input. Refused claims remain filtered before Go context. Preserve exact graph,
evidence ordinals and the four original full raw passes. Attribute two of those
passes to canonical dispatch rather than restoring an unfiltered Go traversal.

Bound decoded report values to depth256 with iterative validation, independently
of interpreter recursion limits. Preserve byte caps, raw length/SHA provenance,
malformed/redaction refusal categories and KeyboardInterrupt propagation.
This adds no runtime option or arbitrary JSON acceptance path.

Exclude only the explicitly opt-in Rust-pilot package from the legacy source
census, asserting that exclusion without enrolling it as legacy. Append only
the already-accepted forward admission to the historical test expectation;
retain the exact inherited commit, parent, hops and all authority validation.

Add bounded meaningful unit and connected filesystem/process/storage regression
coverage around these contracts. Native test stand-ins confer no platform
qualification. Complete local suites/coverage, new dependencies, changed pins,
new parsers, host activation, emulation and test-runner policy remain excluded.

Append new observations/allocations/reservations while preserving every old
row and legacy root ceiling. Require fresh approval/nonce/before-ledger and
reservation binding, reject spent CI121 authority, and bind unchanged public
main and the exact staging synchronize before. Refresh only changed source

scenario, artifact, threshold and guest parser byte. Retain old ARM/AMD evidence
bound to its original source; it is not current whole-manifest qualification.

Permit one ordinary staging push and at most one descriptive PR #23 refresh,
keeping it draft. No manual duplicate, automatic retry, CI123/start34, PR state
churn, main/tag promotion or package release. A coverage-only result does not
justify another standalone campaign; continue approved roadmap coverage work.

## Consequences

execution or fabricated capability/native credit. Whole-candidate, Local Rust,
full W6, scientific comparison, image and release acceptance remain separate.
Hosted CI retains responsibility for complete populations and exact coverage.
