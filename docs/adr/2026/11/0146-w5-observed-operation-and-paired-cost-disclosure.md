Its single application start brings the observed total to 27. Hard coverage

## Decision

### Actual operation evidence

Add an opt-in, versioned evaluator-owned observed-operation record at existing
execution/journal boundaries. Prefer an optional structured field on existing
query-observation events, keeping the six-member journal and strict result-v2
transport unchanged when that compatibility is supported by current readers.
If a strict owner cannot preserve that extension, return the precise conflict
to the parent before implementing a broader artifact protocol.

Construct records from actual typed query inputs, verified publication/profile/
rebuild identities, returned HNSW provenance/plan and FileFusionResult. Capture
actual operation, backend, selected bindings, publication/generation and
representation identity; declared caller request remains separately labelled.
An arm name, expected task mode, grade, truthy mapping or serialized witness is
not evidence of execution. These are inert audit records, never live authority
or a new hostile-Python confinement claim.

Do not add modes to the shared QueryMode vocabulary. Where an internal vector
API has no effective-mode field, preserve null and expose its actual operation
descriptor separately. Metadata representation does not become captured-body
retrieval. Not-run HNSW may disclose performed EXPLAIN work and recorded plan,
but cannot claim an ANN query. Missing/unavailable/refused/failed/truncated
states retain their actual reasons and provenance, with no credited fallback.

Retain bounded actual fusion work/provenance and HNSW configuration/provenance
without changing ranking, exact-rational policy, grades, planner selection,
ef_search/iterative settings or cleanup attribution. Do not force the
calibration planner to select an index. Functional tests may exercise an
explicitly disclosed owned index-selection setting without a speed claim.

Expose component document/query/record/token counts only from the same already
validated sealed response and its digest binding. Never derive zero query
inference from absence of a field or from generation labels. Keep recorded
counts distinct from independently revalidated raw-model evidence.

### Versioned paired report

Add explicit opt-in cloe-w5-semantic-paired-report-v2. Preserve v1 builder,
reader behavior and historical bytes; do not fill, rescore or repin old grade
records. The new report separates declared intent, observed envelope context,
typed operation context, recorded work and comparability gaps. Unknown and
not-recorded remain distinct from false/zero/not-executed.

Project baseline context from the actual hash-bound query_observed envelope.
Read new vector context only through its versioned validated record. Old
vector journals without that record remain explicitly unknown. Report source
locations for every context family; conflicting context/identity/generation/
profile/mode claims refuse rather than silently preferring one side.

An optional raw-model-bundle input may independently validate component counts
against the journal's component hashes, original request/admission, terminal
chain and source closure. No serialized receipt or caller flag substitutes for
the actual bound files. Parsing artifacts grants no live publication or model
execution authority. Missing bundles preserve recorded/unrecorded status.

Retain every declared cell and existing whole/supported/graded/eligible and
reason denominators. Compare literal stored values only. Facts such as matching
publication, observed surface or byte layer are disclosed independently; they
do not define scientific comparability or authorize pooling. No win/tie/loss,
delta/superiority aggregate, threshold acceptance, rescore or hidden selection.

### Work and cost layers

Disclose native raw stdout/direct selected text, serialized envelopes, response
records, artifact/materialized reads, query rows/statements where actually
observed, query timing, correspondence work, inference/import/index/setup and
cleanup as distinct named layers. Use the actual recorded source of each value.
Unknown database wire/internal I/O and agent/model completion spend stay unknown.
Do not convert tokenizer counts into billable completion tokens or dollars.

Keep overlapping timings independent; do not add nested wall/component time.
Campaign cleanup remains charged once to the last retained generation. New
context/report instrumentation has its own disclosed work where measured and
does not become old query cost. A payload cap does not bound underlying work.
The actual 495,781 native cal-07 bytes and unaccepted 65,536-byte proposal remain visible;
no limit is increased or lowered to manufacture success.

## Alternatives and boundaries

Leaving only raw context available preserves evidence but leaves the paired
report insufficient for criteria review. Filling grade fields from intent or
arm labels would invent observations. Replacing v1, rescoring historical data,
forcing HNSW, pooling unlike costs, broadening bodies/corpus or treating a green
core pipeline as optional/scientific qualification are rejected alternatives.

No core CLI/MCP vocabulary, graph/storage schema, production extension/index,
dependency/package/lockfile/runner policy, model/input/label/held-out, privacy
scope or release/platform admission changes. The technical continuation adds
evaluator evidence and faithful disclosures. Full W5 and scientific/held-out
acceptance remain explicit future decisions.

## Binding implementation clarifications

Observed-operation data is a sibling journal field only; strict cells, envelopes
and ResultV2 stay unchanged. Its closed compact fusion projection excludes hits
and rational score fields so v1 interpretation is preserved. Historical v1
outputs remain byte-compatible; new journal hashes truthfully bind new bytes.

Future writes omit reference recall when the exact reference was not completed
or was empty. The new report keeps old literals with unavailable/vacuous
reference disclosures. EXPLAIN ANALYZE is executed SQL work even when ANN is
not selected; existing exact/HNSW elapsed spans are labelled composite.

Intent versus actual mode differences are disclosed; only conflicting observed
claims of the same fact refuse. Vector mode/publication copies are not runtime
evidence. Context projects closed public fields and safe reason codes without
raw vectors, SQL, bodies, locators, principals or denied-source names.

Component counts are recorded from the same validated sealed response with its
digest binding; independently revalidated remains false. The optional raw model
bundle reader is deferred. No absent field is interpreted as zero inference.

Require per-binding completeness, strict types, privacy, 648-cell size headroom,
no-execution paths, v1 compatibility and real publication/readback proof under
exact scoped unit and canonical containerized integration selectors.

Independent source review clarified the failure contract before calibration:
capture preserves refused, unavailable and failed cells when a binding has no
successful query descriptor and the factory-issued public pin and selected
scope remain verified. A pin, scope, identity or capture-invariant refusal
stops trusted capture; it does not promise durable cells for an unverifiable
operation. Existing generation failure evidence remains distinct from a
complete cell journal. A hybrid blocked by its upstream arm records no
attempted query or fusion. Proof must exercise the orchestration and journal
writer together before spending the one-use learned-calibration allocation.

Retained real EXPLAIN evidence has 63 plan nodes, including repeated labels.
The unpublished observation format therefore permits at most 128 node labels
and 16 index names, preserving sequence and repetition. Label syntax and all
existing journal, cell, result and report byte limits still apply. Retained
not-run plans prove parser compatibility, not completed ANN execution or
missing result provenance.

Baseline envelope evidence is distinct from an absent vector-operation record.
Sanitized reasons use an explicit `withheld` marker rather than an absent value.
Recorded component counts populate matching generation disclosures with their
sealed-response trust status; missing historical counts stay unknown. The
495,781-byte cal-07 figure is labelled as a historical reference. Repeated
artifact reads must agree with the first hash-validated source binding.
