## Decision

### Admission and refusal

Use one evaluator-owned admission rule before candidate access in the W5
baseline path. Recompute it from the independently read publication and its
matching frozen policy. A caller mapping, serialized decision, dataclass or
boolean flag is not authority. Preserve pre/post publication validation and
policy-digest checks at execution, correspondence and grading boundaries.

Distinguish admitted public bindings, observed denials, policy-declared denials,
undeclared selections and declared-public bindings absent from the accepted
publication. A declared private binding may be absent from the publication;
the pin-bound policy can still justify an evaluator precheck refusal. Record
that enforcement layer and that backend enforcement was not observed.
Undeclared or missing public selections fail closed without execution and
without invented privacy or safety credit. Missing graph configuration cannot
silently authorize a query.

Any authorization denial in a selected mixed scope refuses the whole W5
request. Do not silently execute a public subset or leak other-arm hits through
fusion. Preserve actual backend, mode, selection, omissions and refusal reason.
Body-role and body-retention restrictions apply to body surfaces; public feed
metadata retains its existing non-body capability outcome. Binding/graph privacy
denials are not inferred from role names or task/gold labels. Preserve the
frozen expected refusal code `binding_privacy_not_authorized` for cal-21/22.

Derive an actual refused result before considering arm applicability in the
versioned W5 grading path. Applicability cannot turn a refusal into unavailable.
Safety `null`, unavailable and absent-answer results remain distinct from a
correct explicit refusal. Historical grades and serializers are not repinned.

### Scope correspondence and current readback

Reuse the product lexical prefix normalizer, then impose strict evaluator raw
checks. Admit only the unchanged canonical form or one trailing slash; reject
whitespace padding, repeated separators, traversal and unsupported forms.
Do not case-fold or Unicode-normalize paths. Treat `%` and `_` literally.

Keep the frozen task's raw prefix and exact selection meaning. A trailing slash
requires descendants: it must not admit a file equal to the directory name.
Canonical equality alone cannot prove correspondence. Establish equality of
the actual selected scope against the accepted publication/materialization, or
retain a visible gap. Recompute any recorded normalization witness during
verification. Out-of-scope hits refuse correspondence rather than disappearing
from the evidence. Test a same-name file and a `shared2` sibling explicitly.

Current-observation readers retain accepted run/repository fences, validation
of every matching metadata row, scope filtering before pagination, and complete
omission/has-more propagation to graph envelopes. Shared historical MCP search
and canonical topology are unchanged.

Define any claimed cross-backend matching profile from actual helper semantics,
including JSON serialization. Locale-dependent prefilters must not remove or
crowd out valid matches before the common predicate. An ASCII query can also
interact with non-ASCII rows. Prove the selected fixed SQL/Python approach on
real SQLite/PostgreSQL, including escaped paths, structural JSON, Unicode and
page boundaries. Unsupported equivalence remains explicit; do not add a new
body-search capability to metadata graph arms to make cal-20 pass.

### Paired evidence

Add a versioned, read-only paired-evidence report over hash-bound journals and
supplementary results. Reuse existing grading, strata and exact-rational fusion
semantics. Join generation/task/arm/repetition from recorded identities, never
array position. Retain duplicate, missing, failed, inapplicable, refused and
unavailable cells and their distinct denominators and reasons.

Emit descriptive per-pair stored values with explicit comparability gaps.
Do not add win/tie/loss or superiority aggregates, rescore old observations or
retroactively accept criteria. Keep ANN correctness separate from relevance,
and missing measurements explicit. Preserve generation-2 document-only and
zero-vector-query limitations in whole populations. Unknown I/O stays unknown;
overlapping timing components are not added twice. Native cal-07's 495,781 raw
bytes and the unaccepted 65,536-byte proposal stay visible.

Old six-member journals and result-v2 archives remain readable and unchanged.
Version new admission/grading/report evidence explicitly and bind it to current
source. Decoding serialized evidence never authenticates a live publication.

## Proof and delivery

Update exact unit and containerized integration owners for changed boundaries,
using the canonical runner with `--no-coverage`. Prove known-private but absent,
unknown, mixed, inherited, retention, non-body, forged, stale and policy-drift
cases; refusal/applicability precedence; path normalization without widening;
real matching/pagination parity; and tampered/missing/duplicate report members.
Inspect genuine adjacent lexical/projection/publication contracts for the
remaining 12 unit and 233 integration branches below the 87%/82% aims. Add only
useful behavioral evidence; thresholds, denominators and exclusions stay fixed.

Batch the connected behavior and evidence work before public CI. Aim for the
operator's substantial batch without filler. Independent resulting-state review,
fresh scoped proof, a current campaign binding and an exact-commit report precede
publication. This ADR allocates no application start, optional model execution,
local complete suite or public trigger. Any later same-model calibration must
be separately predeclared after source review with immutable input/source
archives and the existing artifact/runtime/privacy checks.

## Boundaries and alternatives

No core CLI/MCP vocabulary, canonical schema, production index, package or
dependency, workflow, runner policy, model, corpus, query, gold, held-out,
private input, live deployment or main promotion changes. No application/SDK
build or local coverage. All file-length and numerical debt ceilings remain.

Leaving every gap merely documented preserves history but does not repair the
current behavior. Treating absent bindings as private, accepting normalized
strings without scope proof, dropping unmatched cells or inventing thresholds
would manufacture evidence; those alternatives are rejected. A supported
equivalence gap is preferable to an unsupported parity claim.

Rollback removes only these evaluator changes and invocation-owned outputs;
accepted publications, canonical history and all retained attempts remain.
