- one ordinary staging synchronization of the existing draft PR #23 against
  unchanged public main `5ad00d162ad8a04430874275246a53227578c533`;

These are the normal pipeline work of this newly requested milestone, not
additional local build or acquisition authority. Local complete suites,
Python coverage, application/SDK builds, native parser commands and new
dependencies remain excluded.

Append the authenticated CI122 consumption observation to the standard ledger
view, preserving its previously recorded observation and every historical root
and list prefix. Append the new allocation, reservation and source-pin lineage.
Use a fresh nonce and approval/reservation hashes, bind the exact predecessor
staging ref and main base, and reject spent CI122 credentials as well as every
earlier replay. Preserve strict ordinal, attempt, lower and upper cap checks.

Refresh the D12 candidate/build-context binding for the actual new source.
Refresh only changed existing host-source digest rows in the Rust qualification
closure. Guest parser, dependency pins, fixtures/golds, profiles, artifacts,
scenarios and thresholds stay unchanged. Old ARM/AMD evidence retains its
original source and manifest binding; the hosted component command qualifies
the successor itself.

Final publication requires scoped grant/manifest proof, retained-code and
privacy/hygiene checks, independent `claude_only` APGR review under the approved
milestone route, a parent disposition, and an exact commit report. The user’s
normal `dynamic_default` route resumes for later milestones. At most one
descriptive PR refresh may accompany publication; it remains draft.

No manual duplicate, automatic retry, CI124/start35, main/tag promotion,
package release, Local Rust, full W6/W7, scientific or image/production
acceptance follows. A coverage-only deficit accrues with substantive roadmap
work under the operator's existing direction.

native evidence. Conditional local reservation is not execution, hosted success
or image acceptance. Independent review or a failed proof blocks publication
until corrected within scope; no old evidence is relabeled.
