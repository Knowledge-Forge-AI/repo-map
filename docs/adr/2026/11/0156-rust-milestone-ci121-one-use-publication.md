## Scope and verification

Change only grant/candidate metadata, ordinal-specific admission guards and
their exact unit/containerized integration owners, plus this decision and
the public-safe exit record. Run proportional no-coverage scoped proof,
final binding, retained static enforcement, privacy/hygiene checks and fresh
independent dynamic_default review before the commit/report and single push.
Use Samuel Leighton Lair <sam.lair@knowledge-forge.ai> for public author and
committer. At most one descriptive PR title/body refresh is permitted, keeping
its draft status and refs. The public export withholds docs/status; retain its
established tools/ci exit convention for this public checkpoint.

Complete local suites, local coverage, SDK/application image builds, extra
acquisitions, dependencies, pins, runner/job/permission/timeout/threshold or
retry changes, emulation, main/tag promotion, PR state churn, package release,
container-free Local Rust, full W6 and v0.1 acceptance remain excluded.

## Alternatives and consequences

Holding publication preserves component evidence but cannot obtain hosted AMD
or full product/coverage results. Reusing CI120 would violate its consumed
event/campaign binding. The one new attempt supplies candidate-bound hosted
evidence; failure preserves consumption and requires a new operator decision.
