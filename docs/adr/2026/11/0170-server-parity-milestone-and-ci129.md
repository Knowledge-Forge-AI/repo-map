## Alternatives and rollback

Publishing each source correction would spend qualification capacity without
a useful milestone boundary. Reusing old grants or weakening strict lineage
would misstate authority. Both are rejected. A later correction requires a
forward source change and fresh manual campaign selection; never rewrite this
published phase or treat a failed attempt as unspent.
