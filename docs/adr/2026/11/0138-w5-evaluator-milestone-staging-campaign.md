## Context and authority

The W5 model-independent foundation and the accepted route-A artifact path are
separate authorities. The current candidate's evaluator, generator, fusion,
ANN and JSONB owners form a substantial milestone exceeding 20,000 lines.
The retained two-generation calibration is mechanically verified; generation 2
has document-only inference and no supported metadata-vector query.

CI106 attempt 1 (run 41382023561) qualified the prior staging candidate
`a300dc82d317ecde5646e4e90717b5eaa4aee8db` against main base
`5ad00d162ad8a04430874275246a53227578c533`. Its native AMD start 23 and

## Decision and bounded allocation

Reserve at most one new native `linux/amd64` application start:
cumulative maximum 24 after predecessor
start 23. It is for CI107 attempt 1 with one ordinary fast-forward staging
synchronization of PR23. There is no second start, automatic retry, rerun,
duplicate staging push, main/tag/release promotion, PR mutation or live
deployment. Hosted complete-population gates remain owned by CI107.

Bind the successor to a fresh nonce, reservation digest, authority digest,
full historical consumption ledger, exact candidate/source context and the
unchanged approved SDK recipe. Reject old-nonce, old-source, stale-context and
reservation replay before any build or publication. A Go source rename changes
the application context; the final candidate and runtime binding must include
the actual rename set rather than borrowing the predecessor context.

The SDK recipe, core package, dependencies, lockfiles, runner/workflow policy,
coverage gates and upstream Debian informational treatment remain unchanged.
No local application or SDK build is part of this allocation. Ordinary scoped
proof uses exact selectors with `--no-coverage`; complete populations and
assembled-system qualification remain hosted-only.

## Required predicate before publication

The parent must bind and retain, before any staging action:

1. actual two-generation retained public calibration evidence, with source,
   fixture, task, policy, publication and artifact closure declared before
   queries;
2. the final scoped unit and containerized integration results, static
   enforcement, checks and privacy receipts, all against the exact candidate;
3. the independent dynamic resulting-state review and exact-commit local
   report; and
4. the fresh campaign nonce, reservation, source/runtime context and complete
   historical ledger with old-replay denial.

Every refusal, unavailable, failed, incomplete, truncated, private-binding or
unsupported cell remains visible. Exact cosine is a correctness/ANN reference,
not task usefulness. A sequential scan is `HNSW NOT_RUN`, not ANN success.
Model/import/index/query/cleanup costs remain distinct, and the disposable
JSONB result must report equality, actual plans and cleanup without implying a
production index or schema decision.

These predicates are gates, not claims that they have passed. The optional
profile's terminal result must be reported separately from source proof and
hosted qualification; a reservation or successful core check cannot substitute
for that result.

## Scientific and product limits

This campaign does not accept paired model/calibration success, relevance,
superiority, generalization, fixed savings or a learned-quality threshold. It
does not select or execute held-out tasks, admit private/new-corpus inputs,
admit production pgvector, adopt a schema/index/model, change CLI/MCP behavior,
or close full W5 release qualification. Historical attempts remain immutable;
old scores are not repinned to the successor.

The campaign may leave the relational JSONB path in place and may record poor
or incomplete metadata-vector utility. Such outcomes are valid dispositions,
not reasons to broaden the corpus, alter labels, resample tasks or hide gaps.

## Publication, failure and rollback

Publication is permitted only after the parent adopts the concrete candidate
and all predicates above are true. The one ordinary staging synchronization
then triggers CI107 attempt 1; local evidence does not close hosted
qualification. A failed or canceled campaign retains its exact reservation and
consumption history and requires a new authority for any retry. No main
promotion, tag, release or application activation follows automatically.

Rollback removes only invocation-owned disposable outputs and leaves canonical
publication, historical journals, source bindings, coverage/debt thresholds,
and prior campaign records unchanged. This decision changes only the bounded successor allocation.

## Consequences

This decision provides a single auditable route from a substantial reviewed W5
candidate to one bounded hosted staging attempt while preserving the
model-independent foundation boundary. Actual optional runtime and paired calibration evidence are retained with the
local exact-commit report. Hosted CI107 qualification and full W5 release status
remain open until their own candidate-bound gates pass.
