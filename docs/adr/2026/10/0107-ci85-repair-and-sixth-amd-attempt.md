## Exclusions and failure handling

No seventh start, automatic retry, attempt 2, emulation, ARM application build,
local application/SDK build, dependency/pin/runner-policy change, complete local
suite or Python coverage, manual duplicate campaign, force push, history rewrite,
main promotion, tag or deployment. An actual or uncertain start spends the slot.
The same candidate's failure does not authorize another build. Rollback is a
reviewed forward change and never resets consumed authority.
