# RepoMap Operations Documentation

maintaining RepoMap: operator/runtime AI-agent skills under
[skills/](skills/README.md) and durable operations references that those
skills link to for detail.

Durable references include [SQLite Local](sqlite-local.md) (the first SQLite
Local slice: home selection, commands, MCP matrix and refusals).

Contributor standards and contributor skills live under `docs/contrib/`.
